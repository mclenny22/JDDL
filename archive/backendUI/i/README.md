# Tiny Image Library

A deliberately small, dependency-free image database with a shadcn-style table UI.

- Upload images
- Manage a predefined set of tags
- Create projects with names and descriptions
- Edit image names, tags, and project links directly from table cells
- Search and filter images by tags
- Manage projects in a matching database-table view

## Run

Requires Node.js 22.5 or newer.

```bash
npm start
```

Open <http://localhost:3000>. Runtime data lives in `data/library.db` and `uploads/`.
