# Archived prototypes

These directories preserve previous experiments and reference assets. The
active application is the repository's `frontend/` and `backend/`, started with
`python3 server.py` from the repository root.

V1's live databases and uploads have been moved to root `data/` and `uploads/`.
Archived notes and README commands describe their historical layouts. They are
reference material rather than instructions for the active application.

The prior Page Test Git metadata is preserved locally in the ignored
`.legacy-git/Page-Test/` directory. The archived source is included in the main
repository as ordinary files. Generated dependencies, builds, runtime databases
and uploads are excluded from commits.

The archived V1 shared demo password has been retired; running it requires
`ADMIN_PASSWORD`. The generated `Page Test/project.zip.b64` bundle is retained
locally but excluded from Git; its source files are already archived here.
